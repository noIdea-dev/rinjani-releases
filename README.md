# Rinjani downloads

Rinjani is a private, invitation-only chat for a circle of friends, expats and colleagues in Lombok. This repository holds only the finished app downloads. There is no source code here.

**Start at the install page, it has step-by-step help in English and Bahasa Indonesia:**
https://noidea-dev.github.io/rinjani/
